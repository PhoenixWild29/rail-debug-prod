Privacy Policy

Last updated: March 5, 2026

Rail Debug ("we", "our", or "us") operates the Rail Debug GitHub App and the service available at debug.secureai.dev. This policy explains what data we collect, how we use it, and your rights.

1. Data We Collect

  • Repository content: Code, stack traces, and error logs you submit for analysis via the GitHub App or API.
  • GitHub identity: Your GitHub username, user ID, and installation ID provided by GitHub during OAuth or App installation.
  • Billing information: Payment details are processed by Stripe. We store only your Stripe customer ID and subscription tier — never raw card data.
  • Usage data: Analysis counts per billing period to enforce plan limits.

2. How We Use Your Data

  • To perform AI-powered error analysis on code you submit.
  • To enforce usage limits for your subscription tier.
  • To send Telegram notifications you configure (optional).
  • To improve the accuracy and performance of our analysis pipeline.

3. Data Sharing

We do not sell your data. We share data only with:

  • xAI (Grok API): Code snippets submitted for analysis are sent to xAI's API for processing. xAI's privacy policy applies to data processed by their models.
  • Stripe: For payment processing. Stripe's privacy policy governs billing data.
  • GitHub: As required to operate as a GitHub App.

4. Data Retention

Analysis results are retained for 30 days to power the analysis history feature. Repository content submitted for analysis is not stored beyond the duration of the API request. You may request deletion of your account data at any time.

5. Security

All data is encrypted in transit (TLS) and at rest. We follow GitHub's security best practices for App integrations.

6. Your Rights

You may request access to, correction of, or deletion of your personal data at any time by contacting us. To revoke Rail Debug's access to your repositories, uninstall the GitHub App from your organization or account settings.

7. Contact

Questions about this policy: hello@secureai.dev
